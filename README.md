# 绘枢 · Huishu

当前版本：**1.5.0**。

网页与应用 UI 设计的单入口技能，按需加载方向形成、设计审稿、界面精修、图像参考、品牌板和本地设计资料检索等模块。保留现有品牌、设计系统、内容与技术栈。

## 安装

本仓库根目录就是一个完整技能包，`SKILL.md`是入口，`modules/`和`references/`按任务加载。以 Codex 的用户技能目录为例，将整个仓库克隆到技能目录中的`huishu`文件夹；已有同名目录时先备份并比较，不直接覆盖。

```powershell
New-Item -ItemType Directory -Force "$HOME/.codex/skills" | Out-Null
git clone https://github.com/buyaoqifiyiyi/huishu.git "$HOME/.codex/skills/huishu"
```

也可以下载仓库 ZIP，解压后将包含`SKILL.md`的整个文件夹放入宿主的技能目录。刷新技能列表或重新打开会话后使用`$huishu`；其他支持同类技能结构的宿主按其实际技能目录安装。

## 使用示例

- “用绘枢审计这个界面，先给问题，不改代码。”
- “根据这张截图实现页面，保留现有技术栈。”
- “为这个新产品比较不同设计方向，再实现选定方案。”

只加载当前任务需要的模块。明确的用户要求、只读限制、现有项目规则及宿主工具权限优先；技能文档本身不授予外部操作权限。
