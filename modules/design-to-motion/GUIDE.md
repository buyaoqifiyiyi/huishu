# 设计稿演示动画

用于把已有设计稿、截图、Figma 画面或网站功能视觉做成可还原的演示动画，以及按请求导出 MP4/GIF。先遵循[绘枢入口](../../SKILL.md)与[兼容规则](../../references/compatibility.md)。它是展示制作方法，不接管普通菜单、悬停、提示条和路由交互；这类工作沿用[材质、空间与运动](../art-direction/references/material-space-motion.md)及原项目生命周期。

## 确定产物

| 情境 | 实现和交付 |
|---|---|
| 独立演示、作品展示、设计稿动起来 | 还原源画面，按需要编排加载、功能叙事和循环；交付请求的页面、视频或动图 |
| 网站中的功能卡片、产品视觉、仪表盘样机 | 在原代码/组件/令牌内实现对应区域；真实文字保留 HTML；仅在要求时导出 |

只补齐影响产物的缺项：源参考与可访问素材、需要动的区域、背景保留范围、循环还是单次、交付格式与尺寸。上下文足够就直接推进。没有明确交付格式且无法推断时问一次，不默认附加三种导出；用户只要加载演示时不擅自添加持续故事。截图没有可分图层时说明能还原和不能拆分的部分，不把整张截图平移冒充内部动画。

## 先还原静态画面

源参考决定视觉，不重新选字体、色板、圆角或布局；原有背景、照片和纹理默认保留。先查看图像；Figma 按宿主实际可用连接读取，不假设已装插件或已有令牌。确需 REST API 时从现有安全存储取凭据，按任务授权访问，不打印或保存到产物。

- 从节点树提取坐标、填充、边框、裁切和效果；位置以源画面原点为基准。对要独立运动的内容分层，保留源 z 顺序、遮挡和每角圆角。
- 演示视频可导出文字图层以保留字距；网站文字保持语义 HTML，计数器/打字等需要变化的文字使用匹配字体与度量。不要为追求截图相同牺牲实际网页可访问性。
- 父层导出会带入子内容：子层需要独立动作时重建容器，再导出子层，避免重复烘焙。实例子节点无法导出时查可用父节点，说明降级限制。
- 阴影或模糊可能超出节点几何边界，按实际渲染边界放置；组合表面的整体阴影与每卡片阴影区分。描边覆盖层保持源叠放关系。不要只用元素矩形推断阴影/圆角外溢。
- 背景图按原裁切与变换还原；除非请求移动背景，否则加载、循环重置与镜头变化都保留它。拿不到原图时报告缺项，不静默换平色。

截图没有节点树时，以已知画板或导出比例核对像素与CSS尺寸；无法确认的比例、字体和遮挡区域注明推断，不靠常见屏宽猜成事实。能按源还原的表面/图形用CSS或SVG，照片与可分内容再裁切；网站文字保留语义HTML。运动可能露出截图未包含的背景或下层时，优先索取原图或选择不暴露它的动作；补画属于推测，不能静默当作原设计。检查重建表面时另看未被裁切/提取图层遮住的区域，避免整张相似度掩盖底层错误。

先输出无动画终态供比较。整体与局部差分能辅助定位错位、漏描边、遮挡和阴影；PSNR 只作图像差异证据，阈值取决于分辨率和重采样。轻模糊比较必须报告模糊参数，不能把高分称为“像素完全一致”，也不反复调阈值掩盖结构错误。

## 编排加载与功能叙事

区分连成一体的应用框架与分开的卡片。应用框架可先保留侧栏/正文等表面，仅加载内容；独立卡片可以携带自己的内容整体入场。具体空态与时序服从源设计和用户要求，不把一种空态作为所有页面的硬规则。容器按真实轮廓裁切，入场移动父卡时子内容跟随，避免先穿出卡片。

每个选定视觉先写一句它要演示的动作，再做动画。可参考：

| 视觉 | 可选叙事 |
|---|---|
| 线索、通知、文件列表 | 新条目进入，旧条目顺移，结束恢复源状态 |
| 图表与指标 | 标记沿曲线读取，提示值与图表同步；指标有真实或明确示例依据 |
| 日历 | 查找时段并放入事件，再回到设计状态 |
| 流程与连接线 | 沿实际流向传递脉冲，相关节点依次响应 |
| 输入框与 AI 结果 | 输入、处理中、结果的因果顺序；只改变叙事需要的文字 |
| 媒体视觉 | 进度与播放状态对应；不伪称视频本身已真实播放 |

优先使用源设计已有元素；新增光标/提示等辅助物应符合系统且不污染无动画参考。错开相邻卡片节奏，引导注意力；不用所有卡片同步漂浮代替功能说明。时长、缓动、模糊和镜头按本次内容选择，不沿用上游固定配额、强制全动或默认缩放。

循环应有清楚的进入、演示、恢复与适用的短暂停顿。每条故事在重置前回到约定终态；同时重置 CSS 和 JS 状态，包括遮罩、计数器、打字光标、临时复制层与辅助物。遮挡层的到达/离开顺序要防止隐藏内容短暂穿出。

网站区域在进入视口时启动，适用时仅播放一次入场；持续故事离屏暂停、返回续接，卸载释放观察器和时钟。使用项目已有滚动机制或 IntersectionObserver，不添加无节制逐帧全页工作。`prefers-reduced-motion` 或明确无动画要求显示可读终态；正常动效过程与减动效分别验证。

## 采集、检查与导出

需要视频/动图时读[逐帧采集与导出](references/capture-export.md)。先核对宿主与已安装工具；不自动安装 Playwright、浏览器、FFmpeg 或云服务。Figma、录制和编码缺一项时说明具体受阻环节，继续交付已完成部分，不伪称全部工具已集成。

可用附带的[离线检查脚本](scripts/verify_frames.py)检查已有 PNG 序列。它依赖 Python 与 Pillow；**不会读取 Figma、驱动浏览器、生成动画或编码视频**。`frames_dir` 必须使用相对 manifest 所在目录的路径；`still`、`mask` 和 `fidelity.reference` 的相对路径也按该目录解析，另允许用户授权素材的显式绝对路径。路径格式不扩大素材读取授权：

```json
{
  "frames_dir": "frames",
  "cycle_frames": 120,
  "fps": 30,
  "still": "still.png",
  "empty_frames": [0, 118, 119, 120],
  "rest_frame": 100,
  "mask": "mask.png",
  "overflow_frames": [30, 60, 100],
  "fidelity": {"reference": "reference.png", "min_psnr": 35, "blur": 1.2}
}
```

示例索引仅解释格式，须按真实时间线填写；本例假设结束有空态暂停，100 帧已恢复静态参考。`cycle_frames=N` 要求 `00000.png` 至 `N` 帧含验证端点全部存在，编码只用前 N 帧。`still` 与参考/掩码均须与采集帧同尺寸。 `still` 是恢复检查使用的终态参考：通常取无动画画面；若CSS过渡后的栅格化与单独静态截图有差异，可将它设为同次采集中入场结束、故事开始前的 `landed.png`，并用 `fidelity.reference` 指向独立的静态设计参考。此时恢复帧与落定帧仍精确比较，落定帧与静态参考另按报告的PSNR/差分及人工结构检查核对，不能放宽恢复一致性掩盖状态未重置。mask 白色允许运动，黑色禁止；按容器真实圆角与阴影生成，抗锯齿容差需显式进入掩码。卡片入场时轮廓会移动，`overflow_frames` 只选择轮廓固定的故事阶段；不能拿它冒充全片无溢出检查。需要全程检查时分阶段生成有效掩码或使用对应方法。

```text
python <模块绝对路径>/scripts/verify_frames.py manifest.json --output report.json
```

检查接缝、请求的空态帧、回静态参考、掩码外差异与可选 PSNR；未配置项目标 `skipped`，请求检查失败返回非零。`--output` 使用尚不存在的 JSON 文件，避免覆盖输入或旧报告；不传时标准输出 JSON。只挑少量空态/溢出帧只能证明这些采样帧，想覆盖整个适用区间就列出全部索引。再查看关键时点拼图与最终视频：加载中、已加载、叙事中、恢复、重置。关注残影、跳变、文字可读性和小尺寸下动作是否仍清楚；帧差通过不代表叙事好看。

交付说明实际格式、尺寸、帧率、时长及文件大小，附已执行检查与未还原项。正常浏览器/播放器实际播放、采集帧检查、编码成功和宿主自动发现是不同证据；未观察过程不宣称已完成动态体验验收。
