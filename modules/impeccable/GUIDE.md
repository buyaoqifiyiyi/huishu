# Impeccable 能力 · 概念审稿、诊断与精修

> 绘枢包内工作流程，不是第二个美学预设或独立技能。先遵循[单入口](../../SKILL.md)和[兼容与工具规则](../../references/compatibility.md)。由 Impeccable 固定提交的设计方法改编；版权、改动与选取映射见[来源](references/provenance.md)。本模块不带 Impeccable CLI、检测器、浏览器扩展或会话引擎，不执行其命令。

用于“看着不对”“不够精致”“太普通/缺表现力”、针对性字体/布局/配色修正、增强辨识度、降低实际噪声与上线前精修。先按问题选择增强、整理或减弱，不默认把审美改进等同于减少装饰。已有改造模块负责按授权保留功能并实施改造；本模块补充审稿方法；咨询/转化路径的[到达意图走查](references/review.md#咨询与转化路径按需走查)由 agency-agents 固定提交选择性中文改编，见[整合来源](../../references/integration-20261024-agency.json)。新建/授权完全重构且方向开放时，先走[方向形成](../art-direction/GUIDE.md)和[概念审稿](references/concept-review.md)，在编码前比较候选，成品先核对首屏、阅读路径和材质/空间/运动承诺；小修仍不隐蔽扩大成重设计。

## 先确认这次做什么

从请求、项目指令、实际代码、参考、现有 PRODUCT.md / DESIGN.md 提取：目标页面或组件、核心用户动作、已批准视觉、真实内容、栈、范围和完成条件。文件缺失不等于项目没有视觉系统；不强制创建上下文文件或要求用户重讲已知信息。

按当前页面的使用方式调整审美判断：

| 使用方式 | 优先标准 |
|---|---|
| 促成决定：营销、定价、活动 | 清楚的主张、证据、节奏和行动入口；表达力度服从品牌 |
| 完成任务：后台、编辑器、设置 | 扫读、稳定密度、状态、熟悉组件和高效路径；不强加营销页构图 |
| 理解内容：文档、文章、帮助 | 阅读宽度、章节层级、导航和连续阅读 |
| 观看作品：作品集、画廊 | 作品先行，界面支持浏览与理解 |

## 按问题选流程

| 请求 | 读取 | 交付 |
|---|---|---|
| 开放方向的新建/完全重构，或核对所选概念 | [方向形成](../art-direction/GUIDE.md)与[概念审稿](references/concept-review.md) | 编码前检查内容特异性、候选差异、首屏与手机路径；截图后先审概念再查渲染 |
| 材质、空间、动效或交互节奏 | [材质、空间与运动](../art-direction/references/material-space-motion.md) | 按范围判断表达；实际体验关键时序，不强加纹理、3D或运动库 |
| 审美批评、UI/UX审计、哪里不好 | [审稿](references/review.md) | 先看实际呈现，再独立核对代码/行为；输出有位置和影响的优先问题；只读请求不修改 |
| 访问多但咨询少、客户不信任；营销页/服务详情的咨询或转化路径审计 | [到达意图走查](references/review.md#咨询与转化路径按需走查) | 将真实到达依据或明确假设，对应到具体段落的疑问、证据、阻碍和下一步；不为字号/颜色小修、精确参考实现增加此流程 |
| 字体、层级、布局、留白、颜色 | [排版与色彩](references/type-layout-color.md)中的对应节 | 先讲清一个可验证的设计判断，再改具体角色或关系 |
| 精修、简化、太吵、重点不够、太普通或缺表现力 | [精修、简化与增强](references/refinement.md) | 按真实问题选 polish / distill / quieter / bolder；增强与减弱均可，不依次全跑 |

这些英文词只是流程标签，用户自然语言即可调用，不新增斜杠入口。只加载这次问题需要的参考。

## 共用执行与验收

1. **看现状。** 使用宿主已有浏览器/截图工具和项目启动方式，确认目标与代表性状态；无法运行时检查现有截图的来源、新鲜度及其与代码的对应关系，写明局限。先记录整体判断，再看机械检查，避免被规则命中数量牵着走。
2. **做判断。** 明确最影响结果的问题、期望变化及其依据；保留有效部分。项目约束能解决的选择直接执行，仅对会改变品牌、事实、功能或范围的重要歧义提问。
3. **按保留范围修正。** preserve/extend与精修在原系统内复用组件、令牌，修复原因；replace可按授权重构结构及表达。用户批准参考、品牌/DS、真实事实与原栈优先；字体、色彩、圆角和装饰不因本模块变成全局禁令。不为展示设计能力擅自安装依赖或扩大范围。
4. **批量看成品。** 新建/完全重构先按概念审稿对照首屏承诺、核心内容发现和手机路径，再检查渲染；含运动的任务按[过程验收](../art-direction/references/material-space-motion.md#在真实浏览器中看过程)在正常模式操作并观察中间状态、终态和适用的中断/替代，静态截图不代替动态体验。 同一轮检查目标的桌面/窄屏及实际适用的中间宽度、主要动作、键盘焦点、真实长内容和改动相关状态。一起修正一次观察暴露的问题；有新修改或失败才继续检查，不每调一个像素就截一次图。
5. **收口。** 对照同尺寸前后效果与范围内功能，区分源码检查、浏览器实际观测、交互操作与未验证。记录改变和仍有影响的限制；验证够用后交付，不自动生成报告文件、趋势档案、上下文文件或再开一轮改造。

no-animation 和 `prefers-reduced-motion: reduce` 保持可读、可操作的静态终态；精修不要求加入动效。宿主现有工具可用于查看和检查，但本模块没有运行官方 62 条规则的能力，人工检查不能称为 Impeccable 检测器通过。
